# 📸 AMKOV Admin Dashboard

A modern, high-performance admin dashboard built with **React**, **TypeScript**, **Redux Toolkit (RTK Query)**, and **Tailwind CSS**. 
This platform serves as the central hub for managing the AMKOV e-commerce store, product catalog, customer inspections, locations, and blog publishing.

---

## 🚀 Project Overview

- **Advanced Product Management:** Create and edit products with complex variations (color, size, stock, dynamic pricing), specifications, media galleries, and video uploads.
- **Order & Fulfillment Tracking:** Manage customer orders, process refunds, and track shipping statuses from processing to final delivery.
- **News & Blog Publishing:** Fully-featured rich text editor (React Quill) with SEO settings, taxonomy (tags/keywords), and thumbnail management.
- **Support & FAQ Management:** Create and organize instructional content and customer support FAQs.
- **Analytics Overview:** Visualize store performance, inquiry volume, and inventory health with dynamic charts and low-stock alerts.
- **Premium UI/UX:** Fully responsive, dark-mode optimized interface using **TailwindCSS** and **Shadcn UI**.

---

## 🛠️ Technology Stack

- **React (TypeScript)** – UI framework
- **Redux Toolkit + RTK Query** – State management & efficient API data fetching/caching
- **React Hook Form + Zod** – Form handling and schema validation
- **Tailwind CSS + Shadcn UI** – Styling & accessible UI components
- **React Router** – Client-side routing
- **React Quill** – Rich text editing for products and blogs
- **Sonner & Lucide-react** – Toast notifications & beautiful iconography
